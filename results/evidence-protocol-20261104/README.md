# 证据行动项协议最小原型

原文程序分片并保存codepoint起止位置，模型仅返回片段ID及负责人、期限、分配/完成两字段；程序校验引用和字段来源，正文从原文片段/结构模板渲染，无第二次自由生成。旧业务prompt/评分与输出保留，新协议单独记结果。

GPU27B原测试配置（W4A16/FP8KV/MTP3），原会议4/5/18各5次，共15请求。机械检查15/15，独立fixture关系/完整性预期10/15：会议4为0/5，会议5/18各5/5。机械检查不证明关系正确或完整；会议4虽然姓名都在引用里，仍关联错配，明确标记需要关系复核。

resolve_evidence_owners.py只处理“前N相邻动作＋显式负责人分别为N姓名”、全部动作覆盖且均引用名单的窄模式；拒绝缺行动/重复/未引用/不相邻，不硬编码本fixture姓名或期限。同15原结果派生15/15，改变5条；无新增模型采样，原10/15不覆盖，其他文本模式仍需验证，production_adoption=false。输出见derived-v1/。

CPU突变验证显示机械检查可拒绝虚构引用/负责人/日期/完成状态，不能单独拒绝姓名交换或漏行动，后者由独立fixture检查发现。首次prepare目录因测试混淆引用有效性与语义oracle断言失败，模型0请求；修正后prepare-v2通过，失败目录保留。
