# MoE 少 token tiling 实验（4b-①）

本项仅调整 `QuantGroupedMatmulDequant` 小 M 路径的调度，不叠加 QKVZ 量化，不改变专家权重、scale、路由、GEMV 算术或通信。基线提交 `74f7202`。

候选将各专家内部重复进行的动态 token scale 计算提前至专家循环前，计算所有输入行后仅同步一次；后面的逐专家 GEMV 继续使用原始源码，按原行号读取 scale。仅面向总 M=8/16/24/32、每专家至多 8 行、K=256/2048、FP32 权重 scale 的实验。算子之外未接入候选。

`tools/prepare_moe_prescale_310.py` 从调用者提供的生产 SDK 源码生成隔离构建目录，记录输入头文件 SHA256；仓库不分发 SDK 源码。`tools/bench_moe_prescale_310.py` 先核验官方算子、自编译原调度、候选三方，再对照 CPU FP32 量化整数点积参考，并检查候选逐位重复；正式微基准使用真实激活、256 专家 bank 与累计分组。无 Profile 的 eager/Graph 计时分开，每档 3 对 AB/BA、每臂 256 次调用。CPU 参考容差在真实样本前固定为 `rtol=0.002, atol=0.002`，所有元素均须满足；三方逐位一致与有限值同时为硬条件。

第一轮合成冒烟覆盖 8 案例（M 四档 × K 两类），真实 N 分别为 512、2048，稀疏非均匀分组为 7 个非空专家、每专家至多 2/4/6/8 行。全部自编译对照和候选均与官方算子逐位一致，候选各重复 3 次一致，A/B 最大绝对差为 0；参考与候选均为有限值。CPU FP32 最大绝对误差范围为 0.003858–0.008996，A/B 相同。这次冒烟尚未应用上述正式容差计数，不能直接标作完整 G0 通过。

`experimental/moe_small_m/capture.py` 是隔离副本的 eager 观测钩子，只采真实输入、权重和分组用于算子回放。观测执行方式不用于性能结论。原始张量、完整日志和机器信息仅放忽略的原始目录。

下一步为采集真实路由与权重、无 Profile 微基准并折算收益。只有达到会议回放 3% 的理想进入门槛才继续整模型 G2 与正式回放；逐位不一致则完整 G0/G1/G2。尚未测会议回放、RAG 8K–32K Prefill、通用 1K–32K×C1/C4，WY Prefill 不在本项中改动。未报告实测收益或非劣结论。
