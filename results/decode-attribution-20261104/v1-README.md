**3. 候选与实验草案：按可算的收益/成本排序，数字均为条件预算。**

没有业务逐step的B/context分层Profile，故不能给某个候选**已证实的业务收益上限**。下面统一使用 `U = 476.835925s × mean(rank0,rank1的该类时长/捕获跨度)`；它假设C1/32K份额代表整段业务输出时段、移除后直接缩短关键路径且不增加其他开销。U是**该桶全部消除的外推上限**，不等于可实现收益；2×情景仅把该桶耗时减半。短context特别容易使PA预算失真。既不拿23%累计占比直接乘回放，也不把U相加。共享专家仅是FP16桶的一部分，其独立预算未知，≤A的宽松预算。
