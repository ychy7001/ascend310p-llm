# C8流水线长历史候选性能门禁

沿用服务device-length源码、transdata/compact scale/tile64，仅开启C8_NZ_PIPELINE，在全新c8-pipeline-long-build编译。build.sh/run.sh/run-baseline.sh记录命令；artifacts.txt记录库SHA及CMake选项。没有覆盖服务库，没有接入整模型。

真实a2芯片1，复用tools/bench_c8_long_components_310.py，单层Q1/16 heads/2 KV heads/dim256，5次预热+20次Graph replay+synchronize测量，输出预分配。先候选后基线，分别独立进程；不是同进程交替库AB，仍可能存在少量环境漂移。两边所有长度缓存与同C8码重建的FP16以及Attention输出逐位一致。芯片0处恢复加载阶段，没有并行推理请求；计时不是纯设备kernel事件。
