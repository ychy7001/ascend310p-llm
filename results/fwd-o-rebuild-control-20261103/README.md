# 原始 FwdO 独立重编译对照

生产提交 88eac271 的原始算法，保留独立 API 重命名；复用两种失败补丁的构建框架、依赖和绑定。不是修复候选，原始日志 namespace `maskfix` 仅为 ABI 复用。

固定输入 48 次：镜像 production 与独立重编译各 48/48 在严格门限内且逐位一致。完整链中，重新执行 Torch WY 的 24 次有 18 次越界；frozen-WY-clone 的 24 次本轮无越界。故构建框架不能解释此前两补丁 0/48，而原算法的调用历史相关异常依旧存在。单轮 0/24 不构成消除异常。

`preparation-history` 保留目录准备失败：符号链接/安装文件权限、继承日志及容器名冲突；这些不是算子验证结果。最终状态 complete，验证后已恢复 a2 临时 unit；随后由独立 Dense 基线控制器接管设备。
